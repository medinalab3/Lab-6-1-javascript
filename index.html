Laboratorio de JavaScript

Variables, tipos de datos, arreglos, objetos, control de flujo, funciones, alcance y clausuras.

Abre la consola del navegador (F12 → pestaña "Console") para ver toda la salida de cada ejercicio.

1. Variables, salida de datos y tipos de dato

Declara variables con let y const, usando distintos tipos de dato (string, number, boolean, array, object), y las imprime en pantalla y en consola.


        


        
        

            
2. Arreglos y objetos

            
Crea un arreglo de objetos (estudiantes con nombre y nota), lo recorre, y agrega/modifica elementos dinámicamente.

            
            
    
        
    

        
        
    
            
    3. Estructuras de control (if / else if / else)
    
            
    Ingresa una nota del 0 al 100 y el programa decide la letra correspondiente usando if, else if y else.
    
            
            
            
            
    
        
    

        
        
    
            
    4. Bucles (for, while, do...while)
    
            
    Recorre el mismo arreglo de estudiantes de tres formas distintas para calcular el promedio del grupo.
    
            
            
    
        
    

        
        
    
            
    5. Funciones
    
            
    Define funciones (declarada y flecha) para tareas específicas: calcular el promedio y encontrar al estudiante con la nota más alta.
    
            
            
    
        
    

        
        
    
            
    6. Alcance (scope) y clausuras (closures)
    
            
    Demuestra la diferencia de alcance entre var/let dentro de un bucle, y un contador creado con una clausura que "recuerda" su propio valor entre llamadas.
